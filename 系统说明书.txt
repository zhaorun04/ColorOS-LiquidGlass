ColorOS-LiquidGlass V1.9.205.288.136.1｜HWUI 外层圆角裁剪成本隔离 A/B + 测试窗口修复

一、目标
V288.135 的 Bridge 状态机 C 档未展示稳定掉帧收益，故本版默认回归 A 档。保留 V288.112 GPU 参考帧及所有二维折射、模糊、高光、文件夹和 Dock 光学参数链。

二、实验开关：liquidglass_kyant_outer_clip_ab_288136
0 = 原始路径（默认），保持 Modifier.clip(RoundedCornerShape(cornerDp))；
1 = 仅短时诊断隔离外层 Compose 圆角 clip；只有 gpuReference288110 实际生效且非特殊管线时启用。
注意：档位 1 可能改变圆角裁剪和玻璃边缘外观，不能作为正式无损优化；内部 Kyant 模糊、二维折射、RenderEffect、Highlight/Shadow 和 Source/Backdrop 图层保留。若视觉异常立即恢复 0。
该 A/B 用于判断 HWUI SW Clip Mask 标记与外层 Compose Clip 是否相关；它不能将所有 Clip Mask 归因于该单一节点，也不能直接代表真实 GPU 带宽。

三、日志
KYANT288136_HOST host=... rawMode=0/1 effective=true/false gpu=true/false size=WxH。
只有 B 档 effective=true 且 A 档 effective=false，才能进一步作 A/B 判断。

四、自动化测试（Termux/root）
当前工程根目录：sh lg_test.sh baseline single；sh lg_test.sh clip-isolated single。
可使用 multi 比较多个文件夹场景。建议 A-B-A，以同一页面、尽量相同手势和相近热状态复测。
脚本依次：设置实验开关、重启 Launcher、逐项读取设置和记录失败、检查版本、重置 gfxinfo、录制 15 秒 perfetto、立即获取 framestats、保存日志。数据在 /sdcard/Download/LG136_TestResults/。所有轮次结束后运行 sh lg_test.sh pack 生成 LG136_TestResults.tar.gz，方便一次上传。
注意：gfxinfo 统计窗口接近但不严格等于 Perfetto 时间范围；更严格的同帧关联需要进一步按时间戳筛选。Perfetto 15秒录制期间保持左右滑动；不要将 UI 回调次数当作上屏帧。

五、参数映射及恢复
此版未修改现有 UI / SharedPreferences / Root 快照字段 / Launcher 的光学参数映射；新增 Settings.Global 仅供诊断。恢复：
su -c 'settings put global liquidglass_kyant_outer_clip_ab_288136 0; settings put global liquidglass_kyant_bridge_notify_mode_288135 0; am force-stop com.android.launcher'
