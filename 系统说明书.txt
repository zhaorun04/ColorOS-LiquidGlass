V1.9.205.288.133｜Bridge 通知来源与 Source 消费链诊断版

目标：量化 native bridgeView.onDraw -> post 通知 -> bridgeVersion -> Source 绘制回调的链路。

新增诊断开关（默认关闭）：
  settings put global liquidglass_kyant_bridge_origin_probe_288133 1
  am force-stop com.android.launcher

日志：
  KYANT288133_HOST：Host 初始化、GPU 模式与通知条件
  KYANT288133_WINDOW：每 Host 累计 producer/consumer 计数，每约 2 秒输出
  nativeDraws：原生桥接 View 的 onDraw 次数
  notifyQueued：成功排队的 Bridge 通知
  notifyDelivered：主线程实际递增 bridgeVersion 的次数
  notifyCoalesced：通知已在排队时被合并的次数
  notifyGateOff：通知条件不满足的 native onDraw 次数
  cpuBridgeSamples：原生 View 实际调用 CPU sampleBridgeAt 次数
  sourceDraws：Source 绘制回调次数
  consumerVersionAdvances：相邻 Source 回调之间 Bridge 版本变化的次数
  stableWithNotify：Source 坐标不变而版本变化的次数
  movedWithNotify：Source 坐标变化且版本变化的次数
  stableNoNotify / movedNoNotify：无版本变化的 Source 位置分类
  bitmapGenChanges：Source 所用 Bitmap generationId 变化次数

注意：这些是应用层绘制回调与版本读取统计，不是独立的 GPU 工作或最终上屏帧；
稳定坐标且 Bridge 版本变化并不直接证明可以跳过通知；还可能存在动态光学参数、其他绘制输入变化。
本版不屏蔽通知，不跳过 Source/Backdrop 绘制，不改变 GPU 参考壁纸、折射、模糊、高光与 Dock。
现有 V288.132 观测与裁剪实验开关仍保留；建议将其设为 -1，并关闭其他历史诊断后测试。

抓取：
  su -c 'logcat -d -b all -v brief | grep -E "KYANT288133_HOST|KYANT288133_WINDOW" | tail -60'
关闭：
  su -c 'settings put global liquidglass_kyant_bridge_origin_probe_288133 0; am force-stop com.android.launcher'

原版说明摘要：
V1.9.205.288.132｜单 Host 可见区域与 Bridge 通知 A/B 归因版

承接 V288.131 与单/多文件夹 Perfetto 结果。保持原有光学渲染、GPU 参考帧、动态坐标、模糊、折射和高光不变。

实验键：liquidglass_kyant_visibility_ab_288132（Settings.Global，重启 Launcher 生效）
-1：默认；保留原有 liquidglass_kyant_offscreen_cull_288113 开关行为。
0：A 档，禁用仅针对屏幕外 GPU Bitmap draw 的实验裁剪，开启同样的观察统计。
1：B 档，启用此前 V288.113 的 128px 守护边界屏幕外 GPU Bitmap draw 裁剪，开启相同观察统计。
B 档仅跳过完全屏幕外 Host 的共享参考 Bitmap draw；不跳过 drawContent、Compose 状态读取、Source/Backdrop 录制，不跳过进入视口的预渲染余量。GPU 参考帧未生效的 Host 无 A/B 绘制差异。

日志：
KYANT288132_HOST：每 Host 的开关模式、GPU 参考帧是否生效、实际裁剪设置。
KYANT288132_WINDOW：每 Host 累计 Source 回调数、带 128px 守护区的屏幕外/内次数、位置移动/稳定次数、Bridge 版本变化、位置稳定时 Bridge 变化次数以及屏幕外且位置稳定时 Bridge 变化次数。数值是 CPU Source 回调统计，不是 GPU Pass、上屏帧或确定的冗余事件。
KYANT288113_CULL：仅 B 档命中已有屏幕外 GPU Bitmap 绘制跳过时出现。

建议先确保 Settings.Global liquidglass_kyant_gpu_reference_ab_288110=1，并关闭其它复用、Effect 隔离实验。
A 档：settings put global liquidglass_kyant_visibility_ab_288132 0
B 档：settings put global liquidglass_kyant_visibility_ab_288132 1
每档重启 Launcher，在相同页面进行单文件夹、多文件夹滑动，结合 Perfetto 与 gfxinfo framestats，对比 RenderThread Drawing、Texture upload、Clip Mask 与实际 Janky Frames。
恢复默认：settings put global liquidglass_kyant_visibility_ab_288132 -1；必要时把旧 offscreen_cull_288113 设为 0。

诊断局限：屏幕外判定仅基于 drawPosition 与显示尺寸，不能等同真实遮挡或 SurfaceFlinger 可见性。BridgeOnly 只表示位置稳定但 Bridge 逻辑版本改变，不证明其它输入稳定，也不代表这次 GPU 工作一定多余。本版不修改 UI→SharedPreferences→Root 快照→Launcher 的既有参数映射，仅增加独立 Settings.Global 实验键。
