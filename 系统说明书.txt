ColorOS-LiquidGlass V1.9.205.288.147｜独立 CPU 绘制阶段只读诊断

基线：V288.146.1 已在用户真机恢复 Kyant0 文件夹玻璃。保留 Lens270.run(View) 的代码与参数结构，不再修改其 Host 初始化逻辑。

本版：KyantStageAudit288147.kt 独立辅助类。仅在已经存在的 V288.145 draw 诊断路径中接收屏幕内 Host 位置，在同一次 ComposeCanvas 绘制回调结束时再次采集原生位置；记录 drawDeltaX、stateGapPx、preGapPx、drawDurationMs。没有 PreDraw 入口/出口双采样，不能据此确认 PreDraw 内部变化或屏幕最终呈现帧。无光学坐标修改。

诊断需要同时开启：
su -c 'settings put global liquidglass_kyant_same_frame_snapshot_ab_288142 0; settings put global liquidglass_kyant_strict_snapshot_ab_288143 0; settings put global liquidglass_kyant_coordinate_audit_288144 0; settings put global liquidglass_kyant_frame_correlation_288145 1; settings put global liquidglass_kyant_stage_audit_288146 0; settings put global liquidglass_kyant_stage_audit_288147 1; am force-stop com.android.launcher; input keyevent KEYCODE_HOME'
测试短距离向右滑动松手5~7次，采集：
su -c 'logcat -d -v threadtime | grep -E "KYANT288145_DRAW|KYANT288147_STAGE|KYANT2884_RUN_ERROR|VerifyError" | tail -120'
如发生 Kyant0 文件夹消失，应立即回退已确认正常的 V288.146.1，并关闭 V288.147 和 V288.145 诊断。
结束关闭：
su -c 'settings put global liquidglass_kyant_stage_audit_288147 0; settings put global liquidglass_kyant_frame_correlation_288145 0'

风险：未在当前环境完成 Gradle 构建、D8 字节码校验或 Android 运行时类加载。安装后必须先确认文件夹 Kyant0 和 Dock 玻璃都存在，才开启实验。与 V288.146 不同，本版未增加 run(View) 参数或 PreDraw 回调操作，但不能保证绝无 VerifyError。UI→SharedPreferences→Root→Launcher→渲染的光学参数映射未修改；V288.147 诊断采用独立 Settings.Global 键，默认关闭。
