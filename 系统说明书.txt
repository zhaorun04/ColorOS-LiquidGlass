ColorOS-LiquidGlass V1.9.205.288.97｜回弹采样坐标同步验证版

基线：V1.9.205.288.96.1。保留原有光学渲染，不修改 Shader、Bitmap 采样、绘图平移、Dock、文件夹轮廓与参数映射。

本版仅新增只读 KYANT28897_FINAL 诊断，用来判断 V288.96 的 drawX 与 bridgeX 差异是否进入最终位图采样。

诊断入口：Settings.Global liquidglass_kyant_final_sample_trace_28897；默认 0，开启为 1。Launcher 创建 Host 时读取开关，修改后请重新加载 Launcher。

日志在 LSPosed Vector 模块日志内，由 XposedBridge.log 输出。KYANT28897_HOST 表示 Host 读到开关；KYANT28897_FINAL 在触摸前 150ms 或松手后 850ms 可见时出现。日志对每一触摸/松手周期限流。

关键公式：原始 drawBitmap 源在局部 translationX 平移后，容器 x=0 对应 selectedPos.x-translationX。effectiveX 为这一推算的壁纸全局原点；residualX=drawX-effectiveX。此值仅是 CPU 采样/坐标估计，不能直接证明最终 SurfaceFlinger 合成画面的像素差。

启动：su -c 'settings put global liquidglass_kyant_final_sample_trace_28897 1'，再重新加载 Launcher。保持原有 pipeline 与光学设置不变。

导出：打开 Vector 模块日志导出文件，查找 KYANT28897_HOST / KYANT28897_FINAL。Android logcat 可能不包含 XposedBridge.log。

注意：Vector 作用域必须勾选系统桌面，否则模块无任何光学效果或诊断。
