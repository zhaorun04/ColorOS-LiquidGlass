ColorOS-LiquidGlass V1.9.205.288.149｜Host 坐标几何与 Workspace 回弹时序只读诊断

基线：V288.148（真机测试已确认 Kyant0 文件夹及 Dock 恢复，未见 VerifyError）。
本版只新增 KyantGeometryTiming288149.kt，并从已有独立 KyantPageProvenance288148.kt 读取现有结果；KyantLauncherLens270.kt 与 V288.148 逐字节相同。保留原版 Kyant 透镜、Shader、Dock、UI、SharedPreferences、Root 快照和 Launcher 光学参数，不做位置补偿。

观测：hostAnchorOffsetX 为 nativeX - anchorScreenX（当前真机约 51px，来源尚未证明）。同时记录 anchorPaddingLeft、anchorX、anchorLeft、anchorScaleX 和 translationX 作为可比几何值。每次 release 的相邻样本记录 scrollDx、nativeDx、committedDx、anchorDx、nativePlusScrollDx、composePlusScrollDx 与 stateGapX。全部是 CPU 绘制阶段日志，不代表 SurfaceFlinger 已呈现的帧。NO_PAGE_TARGET_DIFF_OBSERVED 不等于保证从未翻页。

安装后必须先确认原版 Kyant0 文件夹和 Dock 正常；若出现 VerifyError，停用并回退 V288.148。

开启诊断（避免旧实验影响）：
su -c '''settings put global liquidglass_kyant_same_frame_snapshot_ab_288142 0; settings put global liquidglass_kyant_strict_snapshot_ab_288143 0; settings put global liquidglass_kyant_coordinate_audit_288144 0; settings put global liquidglass_kyant_stage_audit_288146 0; settings put global liquidglass_kyant_stage_audit_288147 0; settings put global liquidglass_kyant_frame_correlation_288145 1; settings put global liquidglass_kyant_page_provenance_288148 1; settings put global liquidglass_kyant_geometry_timing_288149 1; am force-stop com.android.launcher; input keyevent KEYCODE_HOME'''

第一轮只做同页右滑回弹，第二轮可单独实际翻页。采集：
su -c '''logcat -d -v threadtime | grep -E "KYANT288149_GEOMETRY|KYANT288148_PAGE|VerifyError|KYANT2884_RUN_ERROR" | tail -120'''

关闭：
su -c '''settings put global liquidglass_kyant_geometry_timing_288149 0; settings put global liquidglass_kyant_page_provenance_288148 0; settings put global liquidglass_kyant_frame_correlation_288145 0'''
