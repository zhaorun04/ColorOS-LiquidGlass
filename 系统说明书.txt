ColorOS-LiquidGlass V1.9.205.288.150｜Compose 状态消费版本与 Workspace 滚动时序诊断

基线：V288.149。新增 KyantStateConsumption288150.kt，复用 KyantPageProvenance288148.kt 的只读事件；KyantLauncherLens270.kt 和 KyantGeometryTiming288149.kt 均保持原样。

新增诊断 KYANT288150_CONSUME：记录 Workspace scrollX、nativeX、PreDraw preX、Compose stateX，同一次 release 相邻采样的 scrollDx/nativeDx/stateDx/preDx、stateRevision，以及绘制回调首次观测到该值的 observedStateAgeMs。首次观测时间不等于 screenPosition 的真实写入时间；stateRevision 是诊断观察序号，不等于内部 Snapshot 版本或 SurfaceFlinger token。调试输出有至少约 40ms 的既有节流，不能证明同一显示帧同步。

不修改 Kyant0 Shader、二维透镜、Dock、文件夹布局、位置 State 值、UI、SharedPreferences、Root 快照或 Launcher 光学参数。新开关默认关闭。原有 V288.145/148/149 的日志继续可用。

先确认安装后 Kyant0 文件夹和 Dock 正常，无 VerifyError。再开启：
su -c 'settings put global liquidglass_kyant_same_frame_snapshot_ab_288142 0; settings put global liquidglass_kyant_strict_snapshot_ab_288143 0; settings put global liquidglass_kyant_coordinate_audit_288144 0; settings put global liquidglass_kyant_stage_audit_288146 0; settings put global liquidglass_kyant_stage_audit_288147 0; settings put global liquidglass_kyant_geometry_timing_288149 0; settings put global liquidglass_kyant_frame_correlation_288145 1; settings put global liquidglass_kyant_page_provenance_288148 1; settings put global liquidglass_kyant_state_consume_probe_288150 1; am force-stop com.android.launcher; input keyevent KEYCODE_HOME'

第一轮仅测试同页短滑回弹 5~7 次，第二轮可单独测试翻页。日志：
su -c 'logcat -d -v threadtime | grep -E "KYANT288150_CONSUME|KYANT288148_PAGE|KYANT2884_RUN_ERROR|VerifyError" | tail -120'

关闭诊断：
su -c 'settings put global liquidglass_kyant_state_consume_probe_288150 0; settings put global liquidglass_kyant_page_provenance_288148 0; settings put global liquidglass_kyant_frame_correlation_288145 0'

如遇 VerifyError 或文件夹退回旧玻璃，立即停止测试，恢复已经正常运行的 V288.149。

本地构建环境未验证 Android Gradle 9.7.1 完整构建，也无法替代 Android 真机 DEX 校验。
