V1.9.205.288.160 — Workspace 绘制位置 A/B 实验

实验目的：V288.159 捕获多个可见 Host 同时出现 11–12px 的 Host/Source 位移失配。本版提供一个默认关闭的绘制位置 A/B，验证这种失配是否与 Host affine 矩阵的二次读取有关。

A（默认）：settings put global liquidglass_kyant_workspace_source_ab_288160 0，保留 V288.155 原绘制路径。
B（实验）：settings put global liquidglass_kyant_workspace_source_ab_288160 1，使用当前 Compose drawPosition 和完整屏幕参考图计算采样目标矩形。
前置开关：288153=1、288154=1、288155=1、288156=0，GPU reference 保持原有配置。
设置后重启 Launcher；每个模式测试相同的右滑不翻页回弹次数。

注意：B 不是对 Workspace 最终 HWUI 合成矩阵的保证。若 B 发生旋转/缩放异常、光学外观回退或抖动加剧，立即设为 0 并重启 Launcher。Dock、Shader 未改动。

状态：源码静态检查及 ZIP 检查；未完成 Gradle 编译或真机测试。
