ColorOS Liquid Glass V1.9.42｜自适应方向性玻璃光学版

基于 V1.9.40 完整源码。

修正 V1.9.40 大文件夹底部整条横向暗带：将尺寸自适应底部线性渐变改为右下角椭圆径向光学暗部。
小 162×162、大 444×444、横 444×162、竖 162×444 均按实际玻璃背景宽高连续计算光学覆盖范围。
左上高光、原生模糊 Alpha、清透预设、诊断功能与 +6px 圆角补偿保持不变。
新暗部仅在原玻璃轮廓蒙版内绘制，不额外描边、不移动直边。

注意：这是光学阴影模拟，不是真实壁纸像素折射。真实折射仍需解决可靠背景采样。

构建：覆盖原仓库源码，提交并推送 GitHub Actions 构建 APK。安装后比较四种文件夹，重点检查大文件夹右下角与直边对齐。

V1.9.42：详细诊断模式下新增 REFRACTION_WALLPAPER_KIND、REFRACTION_LAYER_CONTEXT、REFRACTION_SAMPLING_DECISION。仅判断背景来源和图层上下文，不截图、不读取壁纸像素、不修改原生模糊及现有光学绘制。真实折射尚未实现。

V1.9.43：新增 REFRACTION_SCROLL_SAMPLE、REFRACTION_COORDINATE_LIMIT 只读诊断；仅记录文件夹屏幕坐标、位置变化与父级滚动信息。不会读取壁纸、截屏或产生真实折射。详细诊断开启后生效，最多36条运动采样。

V1.9.44：增加 WallpaperManager.setWallpaperOffsets 请求观察、文件夹身份 ID、屏幕可见性和壁纸请求时间差。
注意：壁纸偏移请求不是系统最终实际渲染坐标，仍无法确认壁纸缩放、裁切、动态壁纸行为；没有采样背景或实现折射。
测试：开启详细诊断，重启桌面，慢速滑动多个桌面页面并导出日志；关注 REFRACTION_WALLPAPER_OFFSET_REQUEST、REFRACTION_SCROLL_SAMPLE。

V1.9.45：大文件夹右下内暗部半径按尺寸平滑缩小（最大约20%），强度最大降低约15%，暗部中心稍向右下外侧移动。小文件夹基准不变，横竖形按宽高平滑插值。原生模糊、圆角+6px和高光保持不变。壁纸偏移仅诊断，未实现真实背景折射。

V1.9.46：增加壁纸原图宽高只读探测（WallpaperManager.getWallpaperFile + BitmapFactory.inJustDecodeBounds）、屏幕真实尺寸与系统期望最小壁纸尺寸；增加 REFRACTION_MAPPING_CANDIDATE 有效性诊断，核对偏移新鲜度、可见性、元数据是否具备。保留 V1.9.45 全部光学外观。壁纸最终缩放裁切尚未验证，不读取壁纸像素、不启用真实折射。部分系统可能限制壁纸文件访问，日志会显示 UNAVAILABLE。

V1.9.47：详细诊断开启时，在壁纸文件尺寸读取成功后，仅一次通过 BitmapRegionDecoder 尝试解码原始壁纸三个 1×1 像素区域，日志 REFRACTION_PIXEL_PROBE。采样坐标为原图坐标，不代表屏幕对应位置；不缓存、不渲染、不进行真实折射。失败时保留既有玻璃外观。壁纸可能含私人图像，详细诊断日志包含三个采样颜色，请按需分享。

V1.9.48：新增 REFRACTION_MAPPING_MODELS 假设坐标模型：CENTER_COVER（按屏幕等比铺满）、DESIRED_WIDTH（假设按系统期望宽度额外缩放）。仅在偏移请求2秒内、文件夹可见、壁纸尺寸已知时输出中心点候选源图坐标。两种模型均未经系统实际壁纸裁切/缩放验证；不渲染折射，不改变原有玻璃光学效果。详细诊断仍会读取3个测试壁纸像素颜色。

V1.9.49：壁纸偏移状态同步。取消2秒绝对过期规则；区分 MOVING / SETTLED / UNKNOWN，静止保留最后有效偏移请求。壁纸ID或屏幕尺寸变化时清除偏移请求，等待新请求。新增 REFRACTION_OFFSET_STATE 日志；映射仍仅为假设，未验证最终裁切或折射。


V1.9.50.1 壁纸坐标双模型视觉对照
- 默认关闭。开启详细诊断与壁纸坐标双模型对照，重启 Launcher 或等待配置刷新。
- 大小合适且完整可见的文件夹右下角显示 CENTER_COVER 和 DESIRED_WIDTH 两块 32x32 原图区域放大图。
- 这是两种假设映射，绝不代表已确认真实壁纸裁切。仅用于与实际桌面壁纸特征目视比对。
- 实验会在 Launcher 内短时读取壁纸文件的小区域像素，不写入磁盘；壁纸更换后建议重启 Launcher。
- 关闭开关即可停止显示。真实折射仍未启用。

V1.9.51 对照图定位与裁剪修正版
- 实验对照仅在大尺寸方形文件夹显示；小、横、竖文件夹不绘制。
- 按 OEM mBackground 原生模糊 Drawable 边界和偏移定位，限制在圆角区域内。
- 标签独立、采样图尺寸受限、中心十字标记；不改变玻璃光学外观。
- 两种壁纸坐标模型仍未验证，不属于真实折射。

V1.9.52：新增独立壁纸坐标目视校准 Activity，打开后通过三个滑块选择屏幕位置及假设的水平偏移。两种候选采样图放在独立校准页面，不遮挡 Launcher 文件夹。校准页用 SHOW_WALLPAPER 显示系统壁纸，可能与桌面实际偏移不同；不提供自动准确性结论。旧版文件夹内对照开关仍保留供兼容，建议关闭。

V1.9.53：修复独立校准页原图 0×0。Launcher 在开启详细诊断后读取系统静态壁纸，生成限大小 JPEG 预览，经 ContentProvider 的 call() 发布到模块应用私有存储；提供方验证调用 UID 属于 Launcher，读取方仅允许本应用 UID。校准页面读取缓存，并检查壁纸 ID 与缓存时效。仅用于人工视觉校准，不代表系统合成器实际裁切映射已确认。使用前需开启详细诊断、重启 Launcher 并打开文件夹，随后进入校准页面。禁用详细诊断后不会生成新的预览；旧缓存最长 24 小时，壁纸 ID 变化则拒绝使用。

V1.9.55：独立校准页新增垂直平移 -400～+400 原始显示像素与缩放修正 0.75～1.25 倍；记录实际窗口 Insets 和预览 View 屏幕 Y；黄色十字使用绝对屏幕坐标映射到 View 局部位置，不再按预览可用高度压缩。两个候选模型仍未验证；这些滑块只影响对照图采样，不修改系统壁纸或 Launcher 玻璃渲染。

V1.9.55：校准预览增加原图中心坐标显示；修复采样矩形靠近边缘时被截断却仍在画面中央绘制十字的错位问题，改为以原图真实采样点为中心、保持固定采样窗口，裁切区域与目标绘制区域同步裁剪；新增点 A/B 手动记录屏幕坐标、垂直平移、缩放修正及两点差异诊断。两点记录并非自动图像匹配；模型仍为假设，真实折射保持关闭。
