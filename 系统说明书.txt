ColorOS-LiquidGlass V1.9.205.288.99｜手势归属与可见帧诊断版

基线：V1.9.205.288.98。本版只增加只读诊断，不修改原有 Bitmap 绘制位移、二维折射、模糊、Dock 或参数映射。建议 V288.98 模式 0 使用，禁用无效的小位移实验。

关键问题：旧版 REBOUND 时间窗只检查 releaseAge，可能跨越下一次触摸；同时旧诊断的较大偏差包含未过滤的离屏 Host。本版在 ACTION_UP 关联 downSerial，排除 ACTION_CANCEL 与后续 ACTION_DOWN，增加当前 Host 可见性过滤，并在同一条日志关联绘制位置、已选 Bitmap 原点、实际平移、有效采样残差、桥接年龄、PreDraw 年龄及 Workspace scrollX/translationX。

设置：
settings put global liquidglass_kyant_sample_sync_ab_28898 0
settings put global liquidglass_kyant_visible_gesture_trace_28899 1
以上在重新加载 Launcher 后生效；关闭诊断设置第二项为0。不要修改现有 pipeline 参数。Vector 中必须勾选桌面作用域。

日志：KYANT28899_HOST（生效情况）、KYANT28899_VISIBLE（仅屏幕内主机且有 Bitmap；每 Host 约55ms限流，每手势最多20条）、KYANT28899_SKIP（离屏/无 Bitmap/跨手势/取消/限流，约500ms限流）、KYANT28899_TRACE_ERROR（异常隔离）。XposedBridge 日志应从 Vector 模块日志导出，不一定进入系统 logcat。Workspace 值仍是诊断时读取的当前状态，不是 SurfaceFlinger 帧时间戳。

真机：依次测试慢速左滑不翻页归位、慢速右滑不翻页归位与快速右滑起始闪动，并上传 Vector 模块日志。出现异常立即关闭28899诊断，确认28898模式0并重启 Launcher。

cd ~/ColorOS-LiquidGlass-V1.0-Source
git add .
git commit -m "V1.9.205.288.99 版本"
git push origin main
