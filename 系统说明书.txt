ColorOS-LiquidGlass V1.9.205.288.102｜零复制桥接与绘制时序诊断版

基线：V1.9.205.288.101 模式 0。针对模式 1 导致的严重抖动与明显掉帧，永久停用 V288.101 的高频 Bitmap.copy 配对实验（即使保留旧 settings 值也不会启用）。

本版仅增加轻量诊断数据：桥接绘制回调耗时、PreDraw 时间戳、Compose Canvas 提交耗时、相邻 Compose 诊断回调时间间隔、桥接/PreDraw 代际与坐标差。未创建新 Bitmap，未修改 Shader、二维折射、模糊、高光和 Dock 参数，也没有增加像素补偿。

开关（启动时读取，修改后重新加载 Launcher）：
liquidglass_kyant_zero_copy_timing_trace_288102=0（默认关闭）/1（开启）
liquidglass_kyant_bridge_pair_ab_288101=0（旧实验已从代码强制停用）
liquidglass_kyant_sample_sync_ab_28898=0（建议）

Vector 模块日志关键字：KYANT288102_HOST、KYANT288102_TIMING。

测试：确认 Vector 模块启用并勾选系统 Launcher 作用域；先确认原本光学正常，设置 timing_trace=1 后重新加载 Launcher；左右不翻页松手归位、快速右滑起始分别测试，再导出 Vector 模块日志。

注意：drawCadenceMs 是同一 Host 的 Compose 回调间隔，并非真实 FPS；canvasSubmitMs 是 CPU Canvas 命令提交时间，不包括 GPU 或 SurfaceFlinger 呈现耗时；bridgeWorkMs 是采样回调工作时间，不代表端到端 Bitmap 更新延迟。本版不会自动修复抖动。

构建：Android Studio / Gradle 项目源码，依赖 Android SDK/NDK 等本地环境。发布前需通过 GitHub Actions 编译及真机测试。
