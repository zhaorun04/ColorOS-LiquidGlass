ColorOS Liquid Glass V1.9.102｜动态折射高光时间平滑实验版

基于 V1.9.101。保留已有静态折射、圆角高光、开机自启动、壁纸同步及 UI。

核心变化：
- 在实际 AGSL 绘制通道引入每个文件夹独立的 temporalOpacity 状态，避免仅依赖 0.0015f 的运动阈值。
- 壁纸偏移变化后，以约 125ms 时间常数渐变到 0.72 的动态折射采样透明度；停止约 115ms 后，以约 310ms 时间常数渐回 1.0。
- 通过 postInvalidateDelayed(16ms) 驱动过渡，不依赖手指持续移动；过渡完成即停止重绘。
- 不修改折射位移强度 22、AGSL 坐标、原生模糊、图标绘制和 V1.9.74 圆角边缘高光。

注意：这是针对 AGSL 折射采样层的时间平滑，不会改变 ColorOS 系统自身壁纸动态效果。如果闪烁来自 OEM 壁纸动画或原生模糊，还需要进一步定位对应图层。

安装：解压源码覆盖原 Git 仓库，提交推送并由 GitHub Actions 编译 APK。建议保留 V1.9.101 APK 备份以便对照。
