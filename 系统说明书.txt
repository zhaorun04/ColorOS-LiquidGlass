ColorOS-LiquidGlass V1.9.205.288.143｜严格坐标来源 A/B 实验版

一、版本定位
基于 V288.142 完整源码；默认不改变原版光学、Shader、壁纸采样、文件夹/Dock 材质以及 UI 设置映射。引入独立且默认关闭的诊断实验开关。尚未完成 Android 编译或真机验证，不可宣称回弹问题已修复。

二、版本特性
新增 Settings.Global：liquidglass_kyant_strict_snapshot_ab_288143；0=关闭，1=严格实验。V288.142 开关保留，建议测试143前设置142=0，便于隔离变量。143=1 时优先使用143路径，142接受统计停用。
仅当 motionAbMode=0、sourceMatrixAb28866=0、Host可见且位于屏幕、松手后0～150ms、PreDraw年龄0～16ms、PreDraw所属release编号匹配、候选与PreDraw差<=8px、候选与原坐标差>0.5px且<=12px时采用新位置。否则使用V288.141原位置路径。不修改Compose状态/Shader，不做固定像素补偿。
新增 KYANT288143_HOST / KYANT288143_SOURCE：分离 zero/corrected/rejected/noPredraw/stale/coordMismatch/offscreen/incompatible 计数；日志并不证明SurfaceFlinger已呈现。该实验只验证严格的回调时序和坐标一致性，并非真正的 SurfaceFlinger 同帧 token 同步。
重要限制：诊断Host可见性与屏幕边界使用屏幕像素和关联Anchor范围的保守近似，不能代替实际SurfaceFlinger裁剪。建议配合肉眼视频与V7 Perfetto对比。

三、终端操作（确认APK编译安装成功后）
cd ~/ColorOS-LiquidGlass-V1.0-Source
# 先恢复两组开关做基线观察
su -c 'settings put global liquidglass_kyant_same_frame_snapshot_ab_288142 0; settings put global liquidglass_kyant_strict_snapshot_ab_288143 0; am force-stop com.android.launcher; input keyevent KEYCODE_HOME'
# 仅开启143实验
su -c 'settings put global liquidglass_kyant_strict_snapshot_ab_288143 1; am force-stop com.android.launcher; input keyevent KEYCODE_HOME'
# 进行5~7次短右滑回弹之后查看
su -c 'logcat -d -v threadtime | grep KYANT288143 | tail -50'
# 实验结束恢复
su -c 'settings put global liquidglass_kyant_strict_snapshot_ab_288143 0; am force-stop com.android.launcher; input keyevent KEYCODE_HOME'
