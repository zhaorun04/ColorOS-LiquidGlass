V1.9.205.288.119｜Provider 语义复用实验版

依据 V288.118 真机日志：h/sProviderReplace=59、h/sProviderInvalidatedLive=49、h/sNodeDetach=0、h/sCold=59。证据支持 Provider 引用更换是静态图层反复失效的主因。
本版只有在静态图层缓存实验开关启用，且前次真正录制的形状与新 Provider 提供的形状均是 Kyant RoundedRectangle、并且值相等时，才保留 GraphicsLayer 的上次录制缓存。缓存键移除 ShapeProvider 对象身份以及 Generic Outline 的路径对象身份，改为录制时的形状值、尺寸、密度、布局方向、高光/阴影全部参数；非白名单 Generic 继续每次录制。绘制的 Outline 仍由原有 Path 获得；真实背景、折射、壁纸、模糊完全不变。
重要：本实现依赖 RoundedRectangle 的 equals 值语义。若上游类没有值相等实现，优化会保守回退为重录，避免潜在视觉错误。更新尺寸或样式仍引发重录，实验默认关闭。不要根据缓存命中率直接推断 GPU 性能收益。

开启：su -c 'settings put global liquidglass_kyant_static_layer_cache_288116 1'，重启 Launcher。
关闭：su -c 'settings put global liquidglass_kyant_static_layer_cache_288116 0'，重启 Launcher。
诊断：su -c 'logcat -d -b all -v brief | grep KYANT288116_LAYER_WINDOW | tail -20'
新增：hProviderRetained / sProviderRetained（新 Provider 的形状值与上一次录制值相等，缓存保留）；hProviderInvalidated / sProviderInvalidated（不能安全保留，缓存失效）。原 ProviderReplace 和 ProviderInvalidatedLive 计数保留，但 ProviderInvalidatedLive 表示替换时缓存原本存在，不一定表示新版本实际清空；需看新增字段。
验证：静态源码审查、ZIP 完整性检查完成；Android Gradle 编译和真机视觉/性能 A/B 尚未完成。真机发现高光滞留、阴影错位、圆角变化不更新，立即关闭实验。

V1.9.205.288.118｜Cold 缓存失效原因审查版（仅诊断）
基于 V288.117 实际真机日志：61 次录制、2 次复用、60 次 Cold、0 次 KeyChanged、9 次 NodeAttach。排查发现 drawBackdrop() 构建 ShapeProvider，而 HighlightElement.update/ShadowElement.update 在 Provider 引用改变时会将对应缓存键清空，这不必伴随节点重建。
本版不删除失效保护，不改变 Geometry、GraphicsLayer 的录制路径、Shader、壁纸采样或实时光学参数。默认关闭原缓存实验，继续使用 Settings.Global 开关 liquidglass_kyant_static_layer_cache_288116（1 启用诊断与实验，0 关闭；变更后重启 Launcher）。
日志 KYANT288116_LAYER_WINDOW 新增：hProviderReplace/sProviderReplace (Provider 引用更换), hProviderInvalidatedLive/sProviderInvalidatedLive (替换时原缓存非空), hNodeDetach/sNodeDetach (节点脱离), hDetachLive/sDetachLive (脱离时缓存非空), hColdRevGt1/sColdRevGt1 (Cold 时轮廓版本大于1)。所有数据均为进程累计值，不是 GPU 帧时。仅当这些字段与 Cold 同步增长才可归因；不能由本日志直接推断 Texture upload 的来源。
实验配置：su -c 'settings put global liquidglass_kyant_static_layer_cache_288116 1'，重启 Launcher，滑动多个文件夹桌面页。
采集：su -c 'logcat -d -b all -v brief | grep KYANT288116_LAYER_WINDOW | tail -20'
建议验证期间继续使用已生效的 GPU 参考帧模式 liquidglass_kyant_gpu_reference_ab_288110=1。画质异常时关掉缓存实验并重启 Launcher。
