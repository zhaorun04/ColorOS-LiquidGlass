ColorOS-LiquidGlass V1.9.205.288.111｜GPU 采样实验入口确认与回退保护版

稳定渲染基线：V1.9.205.288.107.3。V288.111 从 V288.110 源码继承，保留 GPU 实验代码但默认不主动开启。

本版改动：
1. 修正 V288.110 仅当 requested=true 才记录 HOST 的可观测性缺陷；V288.111 无条件输出 KYANT288111_HOST，报告 settings 原始读取值、requested、effective、所有阻断原因。
2. Native 背景回调首次绘制以及每 240 次绘制输出 KYANT288111_NATIVE，用于辅助判断旧路径是否仍被执行。
3. 保留现有 GPU 采样 A/B 实验的全部有效性保护条件、CPU Bridge 回退、Kyant 光学、壁纸采样坐标、Dock 和 UI 映射；没有主动放宽保护条件，也没有加入新的屏幕外裁剪算法。
4. 本版属于入口核查版，不宣称已提高帧率；启动阶段及后续诊断日志可在收集后关闭/清理。

使用方式（Termux）：
su -c 'settings put global liquidglass_kyant_gpu_reference_ab_288110 1'
重启手机后，在桌面滑动，再运行：
su -c 'logcat -d -b all -v brief | grep -E "KYANT288111_HOST|KYANT288111_NATIVE|KYANT288110_DRAW" | tail -80'
如果 effective=false，请使用 blockers 信息决定下一次代码改动；不要为了实验随意改变生产配置。
回退实验：
su -c 'settings put global liquidglass_kyant_gpu_reference_ab_288110 0'
重启手机使 Host 重新创建。
